# Pixelkiez Berlin Restaurant Voice Agent - Campaign Guide

## Purpose

Use a short, transparent AI call to test whether one verified website observation is relevant to a Berlin restaurant operator. Offer a human Pixelkiez consultation only after genuine relevance appears.

## Runtime sequence

1. Pre-call gate: campaign compliance must be externally APPROVED and do_not_contact=false.
2. Identify as a Pixelkiez AI call agent before rapport or pitch.
3. Ask whether about 30 seconds is okay.
4. Speak exactly one selected prospect-specific audit hook.
5. Ask one relevance question.
6. If irrelevant, close cleanly. If busy, respect timing immediately.
7. If relevant, ask one short business-context question.
8. Only then offer a human website review/consultation.
9. Never claim a booking unless a verified calendar tool confirms the explicitly accepted slot.
10. Hard no / do-not-call ends persuasion immediately.

## Restaurant-specific relevance order

Default internal preference when evidence strength is comparable:

1. Broken or unnecessarily difficult reservation/contact path.
2. Inconsistent or hard-to-find opening hours, address, menu or contact details.
3. Unclear restaurant/cuisine proposition in the first viewport.
4. Mobile usability problems on high-intent guest paths.
5. Local search/Google topics only when actually measured; never invent rankings.
6. Recruiting, catering or event flows only when prospect context shows relevance.

## Opening

The compiled agent contains the neutral approved opening. Do not add fake familiarity, fake local identity, or invented claims such as "we noticed you're losing bookings".

## Required production inputs per restaurant

- restaurant name and website URL
- buyer/contact role and, if known lawfully, contact name
- externally approved lead source and compliance decision
- validated website audit packet with evidence pointers
- campaign-specific meeting offer and approved consultant/calendar route
- confirmed ElevenLabs telephony and conversation settings
- do-not-contact state

## Current blockers

This package is a simulation/template build. It is not approved for live cold calling. The German B2B telephone-advertising standard must be evaluated for each campaign/lead source externally; recording is OFF; calendar/CRM/transfer/voicemail capabilities are UNVERIFIED.
